Контейнеризация и окружениеDocker / Docker Compose: Написание Dockerfile для FastAPI-приложения и конфигурации окружения через .env файлы.

Фронтенд: Деплой Next.js приложения на Vercel.

Требования к сдаче проекта 
История коммитов в Git: Репозиторий должен содержать последовательные и понятные коммиты по шагам разработки (не один коммит в самый последний момент).   
Лог работы с ИИ: Экспорт сессии из Claude Code (или скриншоты ключевых диалогов с нейросетью, показывающие реальный процесс взаимодействия без «причесывания»).   
Метрика производительности: Замер производительности через Lighthouse для мобильной версии сайта (добавление отчета или скриншота в репозиторий).
