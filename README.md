# Kvarta Coffee
Лендинг для крафтовой ростерии кофе «Кварта» (г. Минск), разработанный в рамках тестового задания. 
Проект реализован в формате монорепозитория, объединяющего современный фронтенд на Next.js и высокопроизводительный бэкенд на FastAPI.

# Frontend Stack
1) Next.js: Выбран для создания SSR/SSG-ориентированного лендинга с быстрой первичной загрузкой, 
встроенной SEO-оптимизацией и удобной файловой маршрутизацией.
2) Tailwind CSS: Обеспечивает высокую скорость разработки, гибкость при кастомизации UI-компонентов и минимальный размер итогового CSS-бандла.
3) TypeScript: Гарантирует строгую типизацию данных (при работе с формами и API-ответами) и снижает количество ошибок на этапе разработки.

# Дизайн
1) Исследование на Pinterest: Перед началом разработки был проведен анализ референсов на Pinterest по запросам крафтовых кофейных брендов и спешелти-ростерий.
2) Визуальный стиль: В основу концепции легли теплые, глубокие кофейные оттенки, отражающие атмосферу уюта и премиальность продукта.
3) Современные тренды: Использована минималистичная типографика, крупная продуктовая сетка каталога, интерактивные карточки подписок и аккуратные микро-взаимодействия при заполнении формы заказа.

# Backend Stack
1) FastAPI: Легковесный и асинхронный Python-фреймворк, обеспечивающий высокую скорость обработки HTTP-запросов и автоматическую генерацию OpenAPI/Swagger-документации.
2) SQLite: Выбран как оптимальное встроенное реляционное хранилище для тестового задания и локального развертывания. Не требует дополнительного администрирования тяжелых СУБД, 
при этом полностью закрывает задачи надежного сохранения лидов и проверки ограничений.
3) Pydantic: Используется для строгой валидации входных данных (формат белорусских номеров телефонов `+375...`, корректность email и защита от спама).

# Функциональные особенности
1) Интерактивный просмотр кофейных сортов и условий регулярной доставки.
2) Валидация белорусских номеров телефонов и проверка заполнения обязательных полей.
3) Алгоритм ограничения повторной отправки заявок с одного номера/IP в течение 10 минут.
4) Отдельные ТЗ для каждого микросервиса расположены в директориях `frontend/frontend-tz.md` и `backend/backend-tz.md`.
